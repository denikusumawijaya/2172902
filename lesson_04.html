Mengingat Kembali Pertidaksamaan Satu Variabel

Recalling Single Variable Inequalities

Pertidaksamaan linear satu variabel adalah kalimat terbuka yang menggunakan tanda \( <, >, \le, \ge \). A single variable linear inequality is an open sentence using signs \( <, >, \le, \ge \).

Contoh: \( x > 1 \) berarti \(x\) bernilai lebih dari 1 (tidak termasuk 1). Titik pada grafik dibiarkan kosong (open circle). Example: \( x > 1 \) means \(x\) is greater than 1 (1 not included). The point on the graph is an open circle.

Tips & Trik: Garis Bilangan

Bayangkan anak panah. Jika \(x\) lebih besar (kanan), maka arsiran ke kanan. Jika ada tanda sama dengan (\(\le, \ge\)), buat titiknya berwarna penuh (closed circle). Imagine an arrow. If \(x\) is greater (right), shade to the right. If there's an equal sign, make the point solid.

Rumus To The Point: \(\le\) dan \(\ge\) = Titik Penuh; \(<\) dan \(>\) = Titik Kosong.

Sistem Persamaan Linear Dua Variabel

Systems of Two-Variable Linear Equations

Sistem persamaan linear dua variabel terdiri dari dua persamaan linear yang dicari titik potongnya. A system of two-variable linear equations consists of two linear equations where we find their intersection point.

Contoh: \( x + y = 4 \) dan \( x - y = 0 \). Titik potongnya adalah solusinya: \(x=2, y=2\). Example: \( x + y = 4 \) and \( x - y = 0 \). The intersection point is the solution: \(x=2, y=2\).

Tips & Trik: Eliminasi & Substitusi

Gunakan eliminasi untuk menghapus satu variabel dengan menjumlahkan/mengurangkan kedua persamaan. Jika koefisien sama, kurangkan. Jika beda tanda, jumlahkan. Use elimination to remove one variable. If coefficients are same, subtract. If opposite signs, add.

Rumus To The Point: Eliminasi \(a_1x + a_2y = C\) (samakan koefisien salah satu variabel).

Pengenalan Sistem Pertidaksamaan Linear

Introduction to Systems of Linear Inequalities

Sistem pertidaksamaan linear adalah gabungan dua atau lebih pertidaksamaan yang dicari daerah irisan (irisannya) sebagai penyelesaian. A system of linear inequalities is a set of two or more inequalities where the intersection area is the solution.

Titik \((x,y)\) dikatakan solusi jika memenuhi semua pertidaksamaan secara bersamaan. A point \((x,y)\) is a solution if it satisfies all inequalities simultaneously.

Tips & Trik: Uji Titik

Jika bingung menentukan daerah arsiran, ambil satu titik uji (misal \((0,0)\)). Jika memenuhi pertidaksamaan, arsir area yang mengandung titik tersebut. If confused about shading, pick a test point (e.g., \((0,0)\)). If it satisfies, shade the area containing the point.

Rumus To The Point: Irisan semua garis batas = Daerah Penyelesaian.

Masalah Anggaran dan Batasan

Budget and Constraint Problems

Membeli 2 jenis barang dengan uang terbatas. Misal, harga buku \(x\) dan pulpen \(y\). Jika uang Rp 50.000, maka batasannya: \(5000x + 2500y \le 50000\). Buying 2 types of items with limited money. If book is \(x\), pen is \(y\), and money is Rp 50,000: \(5000x + 2500y \le 50000\).

Karena barang tidak mungkin negatif, ada batasan implisit: \(x \ge 0\) dan \(y \ge 0\). Since items can't be negative, there are implicit constraints: \(x \ge 0\) and \(y \ge 0\).

Tips & Trik: Variabel Non-Negatif

Dalam soal cerita dunia nyata (barang, orang, waktu), selalu tambahkan pertidaksamaan \(x \ge 0\) dan \(y \ge 0\). In real-world word problems, always add the inequalities \(x \ge 0\) and \(y \ge 0\).

Rumus To The Point: Uang \(\le\) Kapasitas = Batasan Atas.

Daerah Penyelesaian Sistem

Solution Region of the System

Daerah penyelesaian adalah area yang memenuhi semua pertidaksamaan. Garis batas bisa putus-putus (\(<, >\)) atau solid (\(\le, \ge\)). The solution region is the area satisfying all inequalities. Boundary lines can be dashed (\(<, >\)) or solid (\(\le, \ge\)).

Untuk TKA, sering ditanyakan titik sudut (titik potong antar garis) atau jumlah bilangan bulat di dalam daerah tersebut. For TKA, often asked about corner points (intersections of lines) or the number of integers inside the region.

Tips & Trik: Titik Sudut

Nilai maksimum atau minimum dari sebuah fungsi objektif selalu berada di titik sudut daerah penyelesaian. The maximum or minimum value of an objective function is always at a corner point.

Rumus To The Point: Cari irisan garis \(\implies\) Uji koordinatnya.

Batasan Beruntun dan Logika "DAN"

Consecutive Constraints and "AND" Logic

Sistem pertidaksamaan bisa berupa batasan atas dan bawah untuk variabel yang sama. Contoh: \(x \ge 2\) dan \(x \le 5\). A system can have upper and lower bounds for the same variable. Example: \(x \ge 2\) and \(x \le 5\).

Ini ekuivalen dengan \(2 \le x \le 5\). Daerah penyelesaiannya adalah pita/garis yang dibatasi dua nilai. This is equivalent to \(2 \le x \le 5\). The solution is a strip bounded by two values.

Tips & Trik: Gabungkan Batasan

Jika melihat dua batasan untuk variabel yang sama, langsung satukan menjadi \(a \le x \le b\). Ini mempermudah perhitungan. If two bounds exist for the same variable, combine them into \(a \le x \le b\) to ease calculation.

Rumus To The Point: Sistem = Logika "DAN" (Semua harus terpenuhi).

Sifat Operasi Bilangan Real

Properties of Real Number Operations

Dalam pertidaksamaan, sifat komutatif, asosiatif, dan distributif tetap berlaku pada penjumlahan dan perkalian. In inequalities, commutative, associative, and distributive properties still apply to addition and multiplication.

Contoh distributif: \(a(x+y) = ax + ay\). Ini krusial saat menyederhanakan pertidaksamaan. Distributive example: \(a(x+y) = ax + ay\). This is crucial when simplifying inequalities.

Tips & Trik: Awasi Tanda Negatif

Sifat komutatif TIDAK berlaku untuk pengurangan dan pembagian! \(a-b \ne b-a\). Jika memindahkan variabel, selalu ubah tandanya. Commutative property does NOT apply to subtraction and division! When moving variables, always change the sign.

Rumus To The Point: Pindah ruas = Ubah tanda; Kali/Bagi negatif = Balik tanda pertidaksamaan.

Sistem Persamaan Tiga Variabel

Systems of Three-Variable Equations

Sistem tiga variabel melibatkan \(x, y,\) dan \(z\). Metode penyelesaiannya adalah eliminasi ganda atau substitusi berjenjang. A three-variable system involves \(x, y,\) and \(z\). The solving methods are double elimination or step-by-step substitution.

Tujuannya menyisakan satu variabel, cari nilainya, lalu mensubstitusi balik untuk dua variabel lainnya. The goal is to leave one variable, find its value, then substitute back for the other two.

Tips & Trik: Eliminasi Bertahap

Eliminasi persamaan 1 dan 2 untuk menghapus \(z\). Lalu eliminasi persamaan 2 dan 3 untuk menghapus \(z\). Hasilnya 2 persamaan 2 variabel. Eliminate eq 1 & 2 to kill \(z\). Then eliminate eq 2 & 3 to kill \(z\). Result: 2 equations of 2 variables.

Rumus To The Point: 3 Variabel \(\implies\) Eliminasi 2x \(\implies\) 2 Variabel.

Bilangan Asli Berpangkat Pecahan

Natural Numbers with Fractional Exponents

Bilangan berpangkat pecahan \(\frac{1}{n}\) ekuivalen dengan bentuk akar pangkat-\(n\). Fractional exponents \(\frac{1}{n}\) are equivalent to the \(n\)-th root form.

Contoh: \( 9^{\frac{1}{2}} = \sqrt{9} = 3 \). Jika pangkatnya \(\frac{2}{3}\), maka \( 8^{\frac{2}{3}} = (\sqrt[3]{8})^2 = 2^2 = 4 \). Example: \( 9^{\frac{1}{2}} = \sqrt{9} = 3 \). If exponent is \(\frac{2}{3}\), then \( 8^{\frac{2}{3}} = (\sqrt[3]{8})^2 = 2^2 = 4 \).

Tips & Trik: Pecahan Penyebut Genap

Jika penyebut pangkat genap (seperti 2, 4), basis harus non-negatif (\(\ge 0\)). \((-4)^{\frac{1}{2}}\) tidak real. If exponent denominator is even, base must be non-negative. \((-4)^{\frac{1}{2}}\) is not real.

Rumus To The Point: \(x^{\frac{a}{b}} = \sqrt[b]{x^a}\).

Pemodelan Matematika dari Narasi

Mathematical Modeling from Narratives

Menerjemahkan teks panjang menjadi sistem pertidaksamaan membutuhkan kata kunci: "maksimal", "minimal", "tidak kurang dari", "tidak melebihi". Translating long texts to systems of inequalities requires keywords: "maximum", "minimum", "no less than", "not more than".

"Maksimal" berarti \(\le\), "Minimal" berarti \(\ge\). "Maximum" means \(\le\), "Minimum" means \(\ge\).

Tips & Trik: Variabel Definisi

Tentukan apa yang menjadi \(x\) dan \(y\) di awal. Tulis dengan jelas: Misal \(x\) = banyak roti, \(y\) = banyak susu. Define \(x\) and \(y\) at the start. Write clearly: Let \(x\) = bread count, \(y\) = milk count.

Rumus To The Point: Maks = \(\le\); Min = \(\ge\).

Pertidaksamaan Kuadrat vs Linear

Quadratic vs Linear Inequalities

Jangan tertukar! Pertidaksamaan linear pangkat \(x\) dan \(y\) adalah 1. Jika ada \(x^2\), itu kuadrat. Don't confuse them! Linear inequalities have \(x\) and \(y\) powers of 1. If \(x^2\) exists, it's quadratic.

Meskipun rumus TKA kadang menyelinap bentuk kuadrat, fokus kita adalah mencari daerah irisan linear. Although TKA sometimes sneaks in quadratic forms, our focus is finding linear intersection regions.

Tips & Trik: Faktorisasi

Jika melihat bentuk seperti \(x^2 - 4 \le 0\), faktorkan menjadi \((x-2)(x+2) \le 0\). Solusinya \( -2 \le x \le 2\). If you see \(x^2 - 4 \le 0\), factor to \((x-2)(x+2) \le 0\). The solution is \( -2 \le x \le 2\).

Rumus To The Point: Selisih kuadrat \(a^2 - b^2 = (a-b)(a+b)\).

Sistem Tiga Variabel di Kehidupan Nyata

Three-Variable Systems in Real Life

Misal harga tiket Dewasa (\(x\)), Anak (\(y\)), Balita (\(z\)). Tiga transaksi berbeda membentuk 3 persamaan. Say ticket prices Adult (\(x\)), Child (\(y\)), Toddler (\(z\)). Three different transactions form 3 equations.

Jika yang ditanya batasan tiket (misal total pengunjung \(\le 100\)), maka itu sistem pertidaksamaan 3 variabel. If asked about ticket constraints (e.g., total visitors \(\le 100\)), it's a 3-variable inequality system.

Tips & Trik: Cari Pola Variabel

Perhatikan apakah soal meminta nilai eksak (persamaan) atau batasan jumlah (pertidaksamaan). Baca "total maksimal" atau "tepat". Notice if the problem asks for exact values (equations) or quantity bounds (inequalities). Read "maximum total" vs "exactly".

Rumus To The Point: 3 Batasan = Daerah Ruang 3 Dimensi.

Menentukan Daerah Penyelesaian

Determining the Solution Region

Langkah: 1) Ubah ke bentuk \(y = mx + c\). 2) Gambar garis (solid/putus). 3) Arsir sesuai uji titik \((0,0)\). 4) Irisan = jawaban. Steps: 1) Convert to \(y = mx + c\). 2) Draw line (solid/dashed). 3) Shade based on \((0,0)\) test. 4) Intersection = answer.

Contoh: \(y \ge x\) (garis solid, arsir atas/kiri) dan \(y < 2x\) (garis putus, arsir bawah/kanan). Example: \(y \ge x\) (solid, shade top/left) and \(y < 2x\) (dashed, shade bottom/right).

Tips & Trik: Format \(y = mx+c\)

Mengubah ke \(y = mx+c\) memudahkan menentukan gradien dan arah arsiran (atas atau bawah garis). Converting to \(y = mx+c\) makes it easy to find the gradient and shading direction (above or below).

Rumus To The Point: Kalau \(\le\), y "lebih kecil" (bawah); kalau \(\ge\), y "lebih besar" (atas).

Optimasi Fungsi Objektif

Optimizing Objective Function

Fungsi objektif \(f(x,y) = ax + by\) dicari nilai maks/minimumnya di dalam daerah penyelesaian. Objective function \(f(x,y) = ax + by\) is to be maximized/minimized in the solution region.

Teorema: Nilai optimum selalu berada di titik sudut (pojok) daerah. Theorem: The optimal value is always at a corner point of the region.

Tips & Trik: Uji Semua Pojok

Cari semua titik potong garis. Substitusikan koordinatnya ke \(f(x,y)\). Bandingkan hasilnya. Find all line intersections. Substitute their coordinates into \(f(x,y)\). Compare results.

Rumus To The Point: Maks/Min = Substitusi Titik Pojok.

Sistem Pertidaksamaan Tiga Variabel

Three-Variable Inequality Systems

Pertidaksamaan tiga variabel (\(x,y,z\)) membentuk daerah penyelesaian ruang (3D) yang dibatasi oleh bidang-bidang. A three-variable inequality forms a 3D solution region bounded by planes.

Untuk TKA, sering disederhanakan dengan mencari bilangan bulat non-negatif yang memenuhi, contoh \(x+y+z \le 10\). For TKA, it's often simplified by finding non-negative integers satisfying it, e.g., \(x+y+z \le 10\).

Tips & Trik: Iterasi Batas

Jika \(x+y+z \le 10\), maka maksimum nilai \(x\) adalah 10 (saat \(y=0, z=0\)). Iterasi seperti ini sangat hemat waktu. If \(x+y+z \le 10\), max \(x\) is 10 (when \(y=0, z=0\)). This iteration saves time.

Rumus To The Point: Maks \(x\) = Konstanta (jika lainnya 0).

Soal Cerita TKA: Optimasi Produksi

TKA Word Problem: Production Optimization

Pabrik meja dan kursi. Batasan kayu, waktu, dan permintaan pasar. Ubah semua batasan itu jadi sistem pertidaksamaan. Table and chair factory. Constraints: wood, time, market demand. Convert all to inequality systems.

Tujuannya mencari keuntungan maksimal. Misal keuntungan meja \(P_m\) dan kursi \(P_k\). The goal is max profit. Let table profit be \(P_m\), chair \(P_k\).

Tips & Trik: Tabel Batasan

Buat tabel berisi: Sumber Daya | Meja | Kursi | Tersedia. Ini memetakan soal cerita 1 paragraf jadi 1 persamaan matematis. Make a table: Resource | Table | Chair | Available. This maps a 1-paragraph story to 1 math equation.

Rumus To The Point: Sumber Daya terpakai \(\le\) Sumber Daya tersedia.

Pertidaksamaan dengan Nilai Mutlak

Inequalities with Absolute Values

Nilai mutlak \(|x|\) selalu non-negatif. \(|x| < a\) berarti \(-a < x < a\) (untuk \(a>0\)). Absolute value \(|x|\) is always non-negative. \(|x| < a\) means \(-a < x < a\) (for \(a>0\)).

Ini secara konsep adalah batasan "DAN", \(x\) harus di antara \(-a\) dan \(a\). This conceptually is an "AND" constraint, \(x\) must be between \(-a\) and \(a\).

Tips & Trik: Pisahkan Kasus

Jika bentuknya \(|x-2| \le 3\), bayangkan angka di dalam mutlak sebagai satu kesatuan. \(-3 \le x-2 \le 3\). Tambah 2: \(-1 \le x \le 5\). If \(|x-2| \le 3\), treat the inside as one block: \(-3 \le x-2 \le 3\). Add 2: \(-1 \le x \le 5\).

Rumus To The Point: \(|A| \le b \iff -b \le A \le b\).

Analisis Kesalahan Umus (Miskonsepsi)

Common Misconception Analysis

Kesalahan paling fatal: Membagi/mengalikan pertidaksamaan dengan bilangan negatif TANPA membalik tanda. Most fatal error: Dividing/multiplying an inequality by a negative number WITHOUT flipping the sign.

Contoh Salah: \(-2x > 4 \implies x > -2\).
Contoh Benar: \(-2x > 4 \implies x < -2\). Wrong: \(-2x > 4 \implies x > -2\).
Right: \(-2x > 4 \implies x < -2\).

Tips & Trik: Tarik Tanda Minus

Daripada membagi negatif, lebih aman memindahkan variabel agar koefisiennya positif sebelum membagi. Instead of dividing by negative, it's safer to move variables so the coefficient is positive before dividing.

Rumus To The Point: Kali/Bagi \((-)\) = Balik Relasi (\(>\) jadi \(<\)).
