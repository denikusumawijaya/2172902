Review: Eksponen & Bilangan Real

Bilangan real mencakup bilangan rasional dan irasional. Eksponen bisa berupa bilangan bulat atau pecahan. $a^{m/n} = \sqrt[n]{a^m}$. Contoh: $8^{2/3} = \sqrt[3]{8^2} = 4$.

Rumus To The Point

$a^{-n} = \frac{1}{a^n}$ | $a^{m/n} = \sqrt[n]{a^m}$

Pangkat negatif menjadi pecahan, pangkat pecahan menjadi akar.

Review: Sistem Persamaan Linear

Sistem persamaan linear multivariabel adalah kumpulan persamaan linear yang memiliki variabel yang sama. Solusinya adalah titik potong semua persamaan. Untuk 2 variabel, gunakan substitusi atau eliminasi. Maksimal 3 variabel untuk TKA.

Rumus To The Point

Substitusi: $y = \text{ekspr}$ | Eliminasi: Samakan koefisien, lalu hapus.

Review: Interval & Pertidaksamaan

Pertidaksamaan linear menggunakan tanda $<, >, \le, \ge$. Interval adalah himpunan nilai yang memenuhi pertidaksamaan. Titik berisi (solid) untuk $\le$ atau $\ge$, titik kosong (hollow) untuk $<$ atau $>$.

Rumus To The Point

$[a, b] \rightarrow a \le x \le b$ | $(a, b) \rightarrow a < x < b$

Konsep Dasar Fungsi

Fungsi adalah relasi khusus yang memetakan setiap elemen domain (input) ke tepat satu elemen kodomain (output). Hasil pemetaan disebut range (daerah hasil).

Rumus To The Point

$f: X \rightarrow Y$ | $y = f(x)$

Setiap $x$ harus punya pasangan $y$ yang unik.

Domain, Kodomain, & Range

Kodomain adalah tempat semua output mungkin terjadi. Range adalah output yang benar-benar dihasilkan oleh fungsi. Range adalah himpunan bagian dari kodomain. $R \subseteq C$.

Rumus To The Point

Domain = Input | Kodomain = Semua Output | Range = Output Aktual

Mesin Input-Output

Fungsi bisa diibaratkan seperti mesin: kita masukkan input ($x$), mesan memprosesnya dengan aturan tertentu, dan menghasilkan output ($y$). Aturan pemrosesannya bisa berupa persamaan aljabar.

Rumus To The Point

Input $x \rightarrow$ Proses $f \rightarrow$ Output $f(x)$

Relasi vs Fungsi

Relasi adalah aturan yang menghubungkan anggota dua himpunan. Fungsi adalah relasi khusus di mana setiap elemen domain hanya memiliki tepat satu pasangan di kodomain. Jika satu domain punya dua pasangan, itu bukan fungsi.

Rumus To The Point

Cek Domain: 1 Domain = 1 Pasangan Range.

Tes Garis Vertikal

Cara grafis untuk menentukan apakah suatu kurva adalah fungsi: tarik garis vertikal. Jika garis memotong kurva di lebih dari satu titik, maka itu BUKAN fungsi. Vertical line test. Jika memotong 2 titik, bukan fungsi.

Rumus To The Point

Garis vertikal $x = k$ hanya boleh memotong grafik sekali.

Domain & Range dari Grafik

Domain dari grafik adalah perluasan garis sepanjang sumbu-x (horizontal). Range adalah perluasan garis sepanjang sumbu-y (vertikal). Lihat ujung grafik dari kiri ke kanan untuk domain, bawah ke atas untuk range.

Rumus To The Point

Domain = Sumbu-x | Range = Sumbu-y

Representasi Fungsi Linear & Kuadrat

Fungsi linear memiliki grafik garis lurus $f(x) = ax + b$. Fungsi kuadrat memiliki grafik parabola $f(x) = ax^2 + bx + c$. Pangkat tertinggi linear adalah 1, kuadrat adalah 2.

Rumus To The Point

Linear: $y = ax + b$ | Kuadrat: $y = ax^2 + bx + c$

Representasi Fungsi Rasional

Fungsi rasional adalah fungsi yang berbentuk pecahan polinomial, $f(x) = \frac{P(x)}{Q(x)}$. Grafiknya biasanya memiliki asimtot. Penyebut tidak boleh nol, sehingga menciptakan asimtot vertikal.

Rumus To The Point

Asimtot Vertikal: $Q(x) = 0$

Identifikasi Fungsi Secara Analitis

Secara analitis, persamaan bukan fungsi jika ada variabel $x$ yang memiliki dua nilai $y$ atau lebih. Contoh: persamaan lingkaran $x^2 + y^2 = r^2$ bukan fungsi karena $y = \pm\sqrt{r^2 - x^2}$. Cek apakah ada $\pm$ atau pangkat genap pada variabel $y$.

Rumus To The Point

Jika $y$ punya 2 nilai (ada $\pm$), maka BUKAN fungsi.

Domain Fungsi Rasional

$f(x) = \frac{1}{x-2}$
Asimtot $x = 2$

Untuk mencari domain fungsi rasional, pastikan penyebut tidak sama dengan nol. Penyebut nol akan membuat fungsi tidak terdefinisi (menuju tak hingga).

Rumus To The Point

Syarat: Penyebut $\neq 0$.

Range Fungsi Kuadrat

Range fungsi kuadrat ditentukan oleh titik puncak (nilai maksimum/minimum) dan arah bukaan parabola (atas/bawah). Jika $a > 0$, range $y \ge y_{puncak}$. Jika $a < 0$, range $y \le y_{puncak}$.

Rumus To The Point

$x_p = \frac{-b}{2a}$, lalu substitusi untuk cari $y_p$.

Komposisi & Evaluasi Fungsi

Evaluasi fungsi berarti mengganti $x$ dengan angka. Komposisi fungsi $g(f(x))$ berarti keluaran $f(x)$ dijadikan input untuk $g$. $f(a) = \text{ganti } x \text{ jadi } a$. $g(f(x))$ = input $f$ ke $g$.

Rumus To The Point

Substitusi langsung dari dalam ke luar.

Aplikasi Fungsi Linear

Fungsi linear sangat cocok untuk memodelkan tarif tetap (biaya awal) ditambah biaya variabel per satuan. Misal: $y = 5000x + 20000$. $20000$ adalah biaya tetap.

Rumus To The Point

$y = ax + b$ (a = laju perubahan, b = nilai awal)

Aplikasi Fungsi Kuadrat

Fungsi kuadrat digunakan untuk memodelkan gerak proyektil, luas area, atau keuntungan maksimum. Nilai $y$ pada titik puncak adalah nilai maksimum/minimum absolut.

Rumus To The Point

Cari titik puncak $x_p = \frac{-b}{2a}$ untuk nilai optimum.

Aplikasi Fungsi Rasional

Fungsi rasional sering digunakan untuk memodelkan kecepatan rata-rata atau waktu kerja jika banyak pekerja berubah, karena terdapat pembagian. Semakin banyak pekerja, semakin cepat selesai (berbanding terbalik).

Rumus To The Point

$t = \frac{W}{v}$, di mana $W$ = beban kerja.
